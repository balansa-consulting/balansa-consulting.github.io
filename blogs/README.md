# Publishing an insight

Drop a Markdown file into this directory with front matter like this:

```yaml
---
layout: blog-post
title: A useful title
category: Artificial Intelligence
description: One sentence that introduces the piece.
author: Balansa team
date: 2026-08-01
---

Write the insight in Markdown here.
```

GitHub Pages will publish the page and the Insights index will include it automatically.
